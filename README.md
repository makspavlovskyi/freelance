# Freelance portfolio template (Black Gold)

One self-contained file: `index.html` (HTML + CSS + JS inline, fonts from Google Fonts).

- Preview: open `index.html` in a browser.
- Edit: services, featured work, process and contact links are plain HTML sections — search for the text you want to change.
- Deploy: drop the folder on GitHub Pages, Netlify, Vercel or any static host. No build step.
